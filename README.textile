h1. Mixdrome

A Metro-style Navidrome music client for Windows 8.1 and Windows Phone 8.1, maintained by A-BenLi06. Compatible Subsonic servers are also supported.

h1. Requirements

# Windows 8.1 or Windows 10; Windows Phone 8.1 for the phone client
# Subsonic-compatible music server; Navidrome does not require a Subsonic premium license

To be able to build the source code you need to install the Player Framework addin for Visual Studio which can be found in the libs folder and also you need to have nuget installed in Visual Studio to fetch all the other dependencies.

h1. Navidrome desktop development and verification

Navidrome source defines complete client functionality. MixRadio is the component, layout, UI and design reference. See the "locked Navidrome baseline":docs/navidrome/implementation.md, "functional acceptance guide":docs/navidrome/acceptance.md and "reference/verification commands":tools/navidrome/README.md for the 38-function, 115-case checklist. Functional verification does not require the original MixRadio packages.

The desktop client targets Windows 8.1 Store and runs on Windows 10; the phone client targets Windows Phone 8.1 WinRT. Open @Mixdrome.sln@. See the "PC and WP reference analysis":docs/mixradio/reference-analysis.md, "acceptance workflow":docs/mixradio/acceptance-workflow.md, and "reference and quality tools":tools/mixradio/README.md for reproducible decompilation, desktop build/deployment, regression checks, visual comparison and evidence reports.

The Mixdrome name, package identities and generated icon/tile resources are documented in "branding":docs/branding.md. The new package identity has independent app data; accounts must be configured again.

Build and source checks have passed. Native task completion and original/client visual parity remain pending runtime evidence; the acceptance report preserves those gaps.

h1. Note

If you install the app and when switching away to another app the sound volume lowers automatically, and you are annoyed by this follow these steps:

# Windows key + x
# Control Panel
# Hardware and sound
# Sound
# Speakers
# Properties
# Advanced
# Disable the option "Allow applications to take exclusive control of this device"
# Restart the application and... it works ;)

h1. Contributing

The default stable branch is @main@. Use short-lived branches and pull requests with the required @CI required@ check. See "branch and contribution rules":CONTRIBUTING.md for local regression commands, commit records and native verification boundaries.

Cloud CI runs desktop CLR regressions and source/tool checks. Windows 8.1 AppX packages are built and signed locally, then verified and published to GitHub Releases by CD. See "release workflow":docs/releasing.md for certificate configuration and publishing commands.
